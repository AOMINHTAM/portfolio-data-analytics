User Journey & Full-Funnel Sankey Flow Analysis

Role: Data Analyst Stack: Python 3.x, Pandas, Plotly (graph_objects.Sankey), Clickstream Analytics Scale: 32,000+ Orders / 1M+ Clickstream Sessions

1. Business Scenario & Flow Modeling

Mapped customer paths across Acquisition (UTM Source → Device → Landing Page → Conversion) and Retention (1st Purchase → 2nd Purchase → 3rd Purchase). Identified high-converting traffic channels and diagnosed clickstream touchpoint leaks.

  • Model end-to-end multi-touch attribution without obscuring niche high-converting pathways.
  • Resolve circular loop DAG crashes caused by recurring visits to the same page nodes.
  • Reduce runtime memory consumption when joining 1M+ session and pageview records.

2. Engineering Solutions & Refactoring Notes

  • Prevented 100% of DAG Crashes: Plotly Sankey crashes when a target node points back to an upstream source. Implemented a chronological step prefixing algorithm (.rank()), isolating step transitions into directed acyclic links.
  • 40% Memory Reduction: Filtered schema projections using usecols prior to merging 1.1M clickstream rows, cutting excessive DataFrame memory usage.
  • Dynamic Chromatic Hierarchy: Subdued drop-off volume opacity while highlighting high-intent purchase routes, solving node visual distortion.

3. Key Insights & Commercial Recommendations

  • Traffic Source Discrepancy: gsearch nonbrand on Desktop generated the highest conversion volume, whereas Mobile visitors experienced a 68% drop-off at initial landing pages.
  • Repurchase Flow Cross-Pollination: Flagship buyers of Mr. Fuzzy exhibited an accelerated transition to Love Bear in 2nd order cycles.
