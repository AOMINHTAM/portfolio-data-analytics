User Journey & Traffic Flow Analysis via Plotly Sankey

Role: Data Analyst Stack: Python 3.x, Pandas, NumPy, Plotly (graph_objects.Sankey) Architecture: Acquisition & Retention Directed Acyclic Graphs (DAGs)

1. Business Context & Strategic Objectives

Marketing and product leadership struggled to visualize how users navigated across multi-touch browsing sessions. Static aggregate bar charts failed to depict the sequential transition of traffic sources filtering into landing pages or the specific product sequences adopted by repeat buyers.

  • Build an Acquisition Sankey Flow: UTM Source → Device → Landing Page → Conversion / Drop-off.
  • Build a Retention Sankey Flow: 1st Purchase → 2nd Purchase → 3rd Purchase.
  • Apply visual data storytelling via selective opacity to emphasize "happy paths" (Conversions & Repurchases) while muting terminal drop-offs.

2. Key Findings & Behavioral Flow Insights

  • The "Engaged Leaver" Discovery: Filtering out 1-pageview bouncers exposed that even among actively engaged visitors, the mid-funnel drop-off node remains massive, signaling catalog or checkout friction rather than low-quality ad traffic.
  • Device Conversion Discrepancy: Desktop sessions flow smoothly into the Converted node, whereas Mobile traffic disproportionately terminates at the Drop-off node.
  • The Gateway & Cross-Pollination Journey:
    • The Original Mr. Fuzzy serves as the primary top-of-funnel gateway item, dominating Node 1.
    • Repeat-purchase paths consistently transition from Mr. Fuzzy (Purchase 1) → Love Bear (Purchase 2). Customers rarely purchase the exact same plush toy twice, favoring cross-catalog exploration.

3. Technical Debt Audited & Production Bug Fixes

  • Preventing Circular Link Kernel Crashes: Plotly Sankey diagrams fail when target nodes loop back into identical source nodes. Resolved by prefixing chronological order rankings (`1 - Product A` → `2 - Product A`), ensuring every node in the directed acyclic graph (DAG) remains strictly unique.
  • Memory Optimization on 1M+ Row Joins: Resolved severe RAM bloat by specifying usecols during pd.read_csv() and aggregating standalone tables via .groupby().first() before performing final joins.
  • Visual De-Noising via Dynamic Link Alpha: Engineered an automated link-coloring loop: assigned terminal paths (Drop-off/End) a muted gray rgba(200, 200, 200, 0.4) while highlighting converted progression paths in vivid amber/emerald.
  • Standardized Acquisition Imputation: Cleaned fragmented NaN and arbitrary unknown UTM source strings into a unified, business-readable Direct Traffic node.

4. Actionable Strategic Recommendations

  • Mobile UX/UI Overhaul: Implement sticky "Add to Cart" CTAs and optimize mobile asset delivery to mitigate the high mobile drop-off rate.
  • Lifecycle Email Automation: Suppress Mr. Fuzzy promotions to existing Mr. Fuzzy owners; trigger automated Love Bear campaigns 14 days post-purchase to leverage the natural transition path revealed by the Sankey flow.
